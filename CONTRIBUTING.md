# Участие в разработке

## Как начать

1. Форкните репозиторий
2. Клонируйте свой форк
3. Создайте ветку для своей задачи: `git checkout -b feature/название-задачи`
4. Внесите изменения
5. Убедитесь, что тесты проходят: `python -m pytest tests/`
6. Создайте Pull Request

## Структура проекта

```
src/Extension/          — исходники расширения 1С в формате EDT
  src/
    CommonModules/      — общие модули
    DataProcessors/     — внешние обработки (каждый инструмент)
    Roles/              — роли доступа
  Extension.mdo         — манифест расширения
docs/tools/             — документация по каждому инструменту
tests/                  — тесты структуры EDT
epf/                    — скомпилированные .epf для релизов
```

## Формат исходников

Исходники хранятся в формате [EDT](https://edt.1c.ru/) (1C:Enterprise Development Tools).
Каждый объект метаданных — отдельный каталог с файлами:

- `*.mdo` — описание объекта (XML)
- `Ext/Module.bsl` — код модуля (BSL)
- `Forms/ИмяФормы/` — форма объекта
  - `Form.form` — описание элементов формы (XML)
  - `Ext/Form/Module.bsl` — модуль формы

## Стиль кода BSL

- Имена переменных и процедур — на русском языке
- Каждая процедура/функция — с комментарием назначения
- Экспортные процедуры общих модулей — обязательно документированы
- Обработка ошибок через `ВызватьИсключение` с информативным сообщением

## Ветки и коммиты

- `master` — стабильная версия
- `develop` — текущая разработка
- Коммиты: `feat: описание`, `fix: описание`, `docs: описание`, `refactor: описание`

## Версионирование

Используется [SemVer](https://semver.org/): `MAJOR.MINOR.PATCH`

## Проверка перед PR

```bash
# Проверка структуры EDT
python tests/edt/validate_structure.py

# Все тесты
python -m pytest tests/ -v
```
