# Выгрузка/Загрузка данных

## Описание
Выгрузка объектов 1С в XML-файл и загрузка из XML с контролем конфликтов.

## Возможности
- Выбор файла для выгрузки/загрузки через диалог
- XML-сериализация объектов через механизм `ЗаписатьXML`
- Уведомление о завершении операции

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитВыгрузкаЗагрузкаДанных`
- Для записи файлов: доступ к файловой системе (не ограничен в толстом клиенте)
