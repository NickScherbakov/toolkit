# Консоль запросов

## Описание
Визуальный редактор и отладчик запросов 1С с подсветкой синтаксиса на базе Monaco Editor.

## Возможности
- Редактор текста запроса с подсветкой SQL-синтаксиса
- Выполнение запроса (F5) с выводом результата в таблицу значений и дерево
- Вызов встроенного конструктора запросов платформы
- Редактирование параметров запроса (имя, значение, тип)
- История выполненных запросов
- Просмотр текста запроса в отдельной вкладке

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитКонсольЗапросов`

## Быстрый старт
1. Открыть инструмент через Глобальное меню
2. Ввести текст запроса в редакторе
3. Нажать F5 или кнопку «Выполнить»
4. Просмотреть результат на вкладках «Таблица» / «Дерево»
