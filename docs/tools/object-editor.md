# Редактор объекта

## Описание
Просмотр и редактирование объектов 1С (справочников, документов, регистров и т.д.) по ссылке.

## Возможности
- Ввод ссылки на объект вручную или через выбор
- Отображение всех реквизитов объекта с текущими значениями
- Список табличных частей с количеством строк
- Переключение между режимом просмотра и редактирования
- Сохранение изменений с подтверждением

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитРедакторОбъекта`
- Для редактирования: права «Изменение» на соответствующий тип объекта
