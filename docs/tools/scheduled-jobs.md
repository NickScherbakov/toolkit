# Регламентные и фоновые задания

## Описание
Управление регламентными заданиями конфигурации: просмотр, принудительный запуск.

## Возможности
- Список всех регламентных заданий с именем, наименованием и статусом использования
- Принудительный запуск задания через фоновое задание
- Обновление списка

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитРегламентныеЗадания`
- Для запуска: право на выполнение фоновых заданий
