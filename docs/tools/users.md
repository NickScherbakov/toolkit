# Пользователи

## Описание
Управление пользователями информационной базы.

## Возможности
- Список всех пользователей ИБ с полным именем, статусом блокировки и количеством ролей
- Блокировка / разблокировка пользователя
- Обновление списка

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитПользователи`
- Для блокировки: административные права на ИБ
