# Журнал регистрации

## Описание
Просмотр и фильтрация журнала регистрации 1С.

## Возможности
- Фильтрация по пользователю, периоду начала/конца
- Вывод последних 1000 записей
- Открытие встроенного журнала платформы с применёнными фильтрами (резервный вариант)

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитЖурналРегистрации`
