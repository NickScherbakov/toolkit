# Консоль кода

## Описание
Редактор и исполнитель произвольного BSL-кода на клиенте и сервере. Основа для отладки и быстрых экспериментов.

## Возможности
- Редактор кода с Monaco Editor
- Выполнение на клиенте (`&НаКлиенте`)
- Выполнение на сервере (`&НаСервере`)
- История выполненных скриптов с временем и статусом
- Очистка редактора и истории

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитКонсольКода`

## Предупреждение
Инструмент выполняет произвольный код. Назначайте роль только доверенным пользователям.
