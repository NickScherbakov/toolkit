# Глобальное меню

## Описание
Единая точка входа для всех инструментов 1C Developer Toolkit. Поддерживает поиск и фильтрацию инструментов.

## Возможности
- Полный список всех инструментов с описанием и категорией
- Поиск инструментов по названию в режиме реального времени
- Открытие любого инструмента в один клик
- Категории: developer-console, editor, analysis, navigation, administration

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитГлобальноеМеню`
