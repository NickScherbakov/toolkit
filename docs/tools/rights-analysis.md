# Анализ прав доступа

## Описание
Инструмент для анализа ролей пользователей и проверки прав на объекты метаданных.

## Возможности
- Матрица «пользователь → роль» для всех пользователей ИБ
- Проверка конкретного права (`Чтение`, `Изменение`, `Добавление`, `Удаление`) на объект
- Вывод результата проверки прямо на форме

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитАнализПравДоступа`
