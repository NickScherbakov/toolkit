# Консоль СКД

## Описание
Конструктор и исполнитель схем компоновки данных (СКД) в режиме тонкого клиента.

## Возможности
- Инициализация пустой схемы компоновки данных
- Выполнение схемы с выводом результата в табличный документ
- Доступ к встроенному конструктору схемы

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитКонсольСКД`
