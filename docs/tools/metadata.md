# Метаданные

## Описание
Просмотр дерева объектов конфигурации, поиск по метаданным и анализ структуры хранения.

## Возможности
- Дерево всех разделов конфигурации (справочники, документы, регистры и т.д.)
- Поиск объектов по имени и синониму
- Просмотр структуры хранения объекта в БД (таблицы и назначения)
- Отображение количества объектов в каждом разделе

## Требуемые роли
- `ТулкитПолныйДоступ` или `ТулкитБазовыйДоступ` + `ТулкитМетаданные`
- Для просмотра структуры хранения: привилегированный режим или право на `ПолучитьСтруктуруХраненияБазыДанных`
