## Блокеры динамического тестирования

### 1. База utdemo зависает на старте

**Симптом:** Конфигуратор (`DESIGNER`) и предприятие (`ENTERPRISE`) зависают бесконечно при попытке открыть базу `C:\bases\utdemo11.5.22`. Флаг `/DisableStartupDialogs` не помогает.

**Вероятная причина:** База требует реструктуризации/обновления конфигурации БД — появляется диалог, который блокирует неинтерактивный запуск.

**Что пробовали:**
- `DESIGNER /LoadConfigFromFiles -Extension` → ошибка "Загрузка не должна менять принадлежность объекта"
- `DESIGNER /LoadExt` → зависание (60+ сек)
- `ENTERPRISE /Execute .epf` → зависание (60+ сек)
- COM-автоматизация (`V83.COMConnector`) → не зарегистрирован
- `ibcmd` → не установлен

### 2. Apache не запускается (конфликт битности)

**Симптом:** Скачанный Apache 2.4 (x64) не может загрузить `wsap24.dll` (32-bit DLL из `Program Files (x86)`).

```
Cannot load C:/Program Files (x86)/1cv8/8.3.27.2130/bin/wsap24.dll into server: 
Not a Win32 application
```

**Вероятная причина:** 1С 8.3.27 поставляется только с 32-битными модулями веб-расширения, а скилл `web-publish` скачивает 64-битный Apache.

### 3. IIS не запускается

**Симптом:** `Start-Service W3SVC` завершается без успеха — статус остаётся `Stopped`. Предположительно нет прав администратора или IIS не сконфигурирован.

## Рекомендации для запуска полного тестирования

1. **Открыть базу utdemo вручную** в Конфигураторе, принять обновление ИБ, закрыть.  
   После этого неинтерактивные команды перестанут зависать.

2. **Установить расширение через UI:**  
   Конфигуратор → Конфигурация → Расширения конфигурации → Добавить → выбрать `build/1CDeveloperToolkit.cfe`

3. **Исправить Apache (один из вариантов):**
   - Использовать 32-битный Apache (`httpd-X.X.XX-Win32-*.zip` с apachelounge.com)
   - ИЛИ запустить IIS как администратор и использовать `webinst.exe -publish -iis`

4. **Повторить тестирование** командой:
   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build_and_load.ps1 \
     -InfoBasePath "C:\bases\utdemo11.5.22" -UserName "Администратор (ОрловАВ)" -UpdateDB
   ```
