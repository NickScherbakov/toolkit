# Права доступа — 1C Developer Toolkit

## Модель прав

С версии **0.1.0** обязательна настройка ролей.

## Варианты настройки

### 1. Полный доступ

Назначьте роль `Toolkit: Полный доступ` (`ТулкитПолныйДоступ`).  
Даёт доступ ко всем инструментам Toolkit.

### 2. Ограниченный доступ

**Обязательная базовая роль:** `Toolkit: Базовый доступ` (`ТулкитБазовыйДоступ`)

Плюс отдельные роли на каждый инструмент:

| Инструмент | Роль |
|---|---|
| Консоль запросов | `ТулкитКонсольЗапросов` |
| Консоль кода | `ТулкитКонсольКода` |
| Редактор объекта | `ТулкитРедакторОбъекта` |
| Метаданные | `ТулкитМетаданные` |
| Глобальное меню | `ТулкитГлобальноеМеню` |
| Все функции | `ТулкитВсеФункции` |
| Анализ прав доступа | `ТулкитАнализПравДоступа` |
| Пользователи | `ТулкитПользователи` |
| Регламентные задания | `ТулкитРегламентныеЗадания` |
| Журнал регистрации | `ТулкитЖурналРегистрации` |
| Подписки на события | `ТулкитПодпискиНаСобытия` |
| Поиск и замена ссылок | `ТулкитПоискЗаменаСсылок` |
| Сравнение объектов | `ТулкитСравнениеОбъектов` |
| Монитор лицензий | `ТулкитМониторЛицензий` |
| Консоль СКД | `ТулкитКонсольСКД` |
| Менеджер формы | `ТулкитМенеджерФормы` |
| Выгрузка/Загрузка данных | `ТулкитВыгрузкаЗагрузкаДанных` |

## Назначение ролей

1. Открыть **Конфигуратор**
2. Перейти в **Администрирование → Пользователи**
3. Для каждого пользователя назначить нужные роли на вкладке «Прочие»

## Безопасность

- Инструменты, требующие привилегированного режима (структура хранения, параметры сеанса), доступны только пользователям с соответствующими правами платформы
- Рекомендуется не назначать `ТулкитПолныйДоступ` обычным пользователям — только разработчикам и администраторам
