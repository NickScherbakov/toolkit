# Upgrade guide

## Что изменилось в этом PR

Публичный репозиторий Toolkit получает:

- структурированный каталог инструментов и ограничений;
- автоматические проверки каталога и тесты;
- design doc, migration plan и backlog улучшений;
- обновленные шаблоны для triage.

## Что нужно сделать сопровождающим

1. При изменении списка инструментов синхронно обновлять:
   - `README.md`
   - `data/toolkit_catalog.json`
2. Перед публикацией изменений запускать:
   - `python scripts/validate_catalog.py --report build/validation-report.md`
   - `python -m unittest discover -s tests -v`
3. При выявлении продуктовых проблем, которые нельзя исправить в этом репозитории, создавать issue с пометками:
   - `needs-attention`
   - `priority:<level>`

## Что нужно сделать пользователям

Для пользователей продукта изменений в runtime-поведении нет. Это обновление касается публичной документации и процесса сопровождения репозитория.

## Ограничения

Если требуется реальное изменение Infostart Toolkit, нужен доступ к приватным исходникам, тестам и внутреннему CI продукта.
