## Требования

- 1С:Предприятие **8.3.14** и выше
- Тонкий клиент (основной режим работы)
- Веб-клиент: поддерживается для большинства инструментов

## Установка

### Через расширение конфигурации

1. Скачайте актуальный релиз `.cfe` из [Releases](../../releases)
2. В конфигураторе: **Конфигурация → Расширения конфигурации → Добавить**
3. Выберите скачанный файл `.cfe`
4. Назначьте роли пользователям (см. [Права доступа](docs/access-rights.md))

### Пакетная установка

```cmd
"<путь к платформе>\bin\1cv8.exe" ENTERPRISE /DisableStartupMessages /F"<путь к базе>" /N"<пользователь>" /P"<пароль>" /Execute "<путь>\setup.epf" /C ITK_AUTOINSTALL "<лог>"
```

## Права доступа

С версии MVP **обязательно** назначить роли:

| Вариант | Роли |
|---|---|
| Полный доступ | `Toolkit.FullAccess` |
| Ограниченный | `Toolkit.BasicAccess` + роли на отдельные инструменты |

Подробнее: [docs/access-rights.md](docs/access-rights.md)

## Разработка

```bash
# Клонировать репозиторий
git clone https://github.com/NickScherbakov/toolkit.git
cd toolkit

# Проверить структуру EDT
python tests/edt/validate_structure.py

# Запустить все тесты
python -m pytest tests/ -v
```

Исходники в формате [EDT](https://edt.1c.ru/) находятся в `src/Extension/`.
